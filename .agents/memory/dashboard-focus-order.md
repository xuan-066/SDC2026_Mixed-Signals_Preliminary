---
name: Dashboard focus order
description: User preference for how critical cold-chain information should be prioritized in the SejukGuard dashboard.
---

Dashboard redesigns should change the content hierarchy and layout, not only the colors. Put the highest-severity active incident and its immediate risk values first, then its recommended response and approval state, then the event timeline and general operational metrics. Use a coherent warm palette while keeping critical information unmistakably high-contrast.

**Why:** The user explicitly corrected an earlier palette-focused redesign and asked for the most important operational focus to be clear at first glance.

**How to apply:** When changing SejukGuard's dashboard, preserve real incident data and actions while making the highest-risk situation the first thing users can scan.
