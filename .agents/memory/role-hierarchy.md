name: User privilege hierarchy
description: User-stated expectations for owner, manager, and worker access.
---
Different types of users must have different privileges: the owner has maximum privileges, the manager has medium privileges, and the worker has limited privileges.

**Why:** The user explicitly stated this access hierarchy.

**How to apply:** Preserve this hierarchy when planning or changing permissions. The current Supervisor and Staff labels correspond to the user's manager and worker terms.
